    Nord publishes the CC numbers but not how panel values map to 0–127. Tone Wave comes with values read from an owner's unit, which should suit most people, and everything else starts as an even spread. If a wave lands in the wrong place, Learn reads the real values from your unit. To use it, set the unit one step above the lowest value, press Learn, turn down one click, then turn up one click at a time to the end.

    Back up a kit

    On the unit, hold Shift and press MIDI until the display reads Send, then press Drum Kit Select. The editor captures the dump here. It can't be opened as knobs, because Nord doesn't publish the format, but it restores exactly.

    Nothing captured yet.

    Saving vs. storing

    A dump or Send Kit replaces the kit currently loaded on the unit, and that survives only until you change kits. Use Store Kit on the unit to keep it. Memory Protect ships On, so set it to Pr.Of first.
